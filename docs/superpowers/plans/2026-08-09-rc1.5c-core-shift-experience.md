# RC1.5C Core Shift Experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the normal daily workflow a minimal `כניסה → הפסקה → יציאה` experience while preserving the existing shift, break, salary, notification, recovery, and persistence services.

**Architecture:** Add pure domain decisions for choosing a safe clock-in target and constructing an unscheduled active shift. Keep Home as the orchestrator: it starts an unambiguous scheduled or single-workplace shift immediately, exposes a compact workplace picker only when required, and renders a simplified active panel plus inline quick clock-out review. Existing advanced routes remain available as secondary recovery/edit paths.

**Tech Stack:** Expo Router 57, React Native, TypeScript, Zod domain entities, date-fns, Jest, Testing Library React Native, SQLite repositories.

## Global Constraints

- Preserve scheduled / actual / payable separation and salary snapshots.
- Never silently choose `workplaces[0]`; ambiguous choices require explicit user input.
- Do not ask for expected end, role, salary profile, template, or payable range during an unambiguous normal clock-in.
- Keep stale-shift recovery and active cancellation semantics.
- Do not delete the existing advanced start/end/cancel/expected-end routes in this milestone.
- Use TDD for every behavior change and run the complete repository gate set before commit.

```ts
export function resolveClockInDecision({ shifts, workplaces, now }: ClockInDecisionInput): ClockInDecision {
  const nearby = matchNearbyScheduledShifts(shifts, now, { maximumDifferenceMinutes: 180 });
  if (nearby.recommendedShiftId) return { kind: 'scheduled', shiftId: nearby.recommendedShiftId };
  if (nearby.candidates.length) return { kind: 'choose-shift', shiftIds: nearby.candidates.map((item) => item.shiftId) };
  const active = workplaces.filter((item) => !item.isArchived);
  if (active.length === 1) return { kind: 'workplace', workplaceId: active[0]!.id };
  if (active.length > 1) return { kind: 'choose-workplace', workplaceIds: active.map((item) => item.id) };
  return { kind: 'unavailable' };
}
```
